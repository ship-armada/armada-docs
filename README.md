# armada-docs

Documentation for the [Armada](https://armada.blue) protocol, published at
[docs.armada.blue](https://docs.armada.blue).

Built with [VitePress](https://vitepress.dev) and deployed to GitHub Pages. The docs source and the
contributor workflow live in [`docs/`](./docs/README.md).

```sh
npm install
npm run docs:dev
```

For the TypeScript SDK's API reference, see [sdk.armada.blue](https://sdk.armada.blue)
([armada-sdk](https://github.com/ship-armada/armada-sdk)).
